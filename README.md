# Cloud-Hosted Web Deployment using Amazon S3

## Project Overview
Deployed a static website on Amazon Web Services (AWS) using Amazon S3 Static Website Hosting. This project demonstrates how to host a website in the cloud, configure public access permissions, and make website files accessible through a website endpoint.

## AWS Services Used
- **Amazon S3:** Stored website files and hosted the static website.
- **S3 Bucket Policy:** Configured permissions to allow public read access to website objects.
- **Static Website Hosting:** Enabled website hosting and configured the index document.
- **S3 Website Endpoint:** Used the endpoint to access the deployed website through a browser.

## Project Implementation
1. Created an S3 bucket in the AWS Management Console.
2. Uploaded the website files, including HTML, CSS, JavaScript, and required assets.
3. Enabled Static Website Hosting and configured `index.html` as the index document.
4. Configured bucket permissions and a bucket policy for public website access.
5. Accessed and tested the deployed website using the S3 website endpoint.
6. Documented the deployment process with screenshots.

## Architecture

**User Browser → Amazon S3 Website Endpoint → S3 Bucket → Website Files (HTML, CSS, JavaScript, Assets)**

## Key Learnings
- Understanding Amazon S3 and cloud-based static website hosting.
- Creating and configuring S3 buckets.
- Managing S3 bucket policies and public access permissions.
- Understanding the difference between S3 object URLs and static website endpoints.
- Deploying and testing a static website on AWS.
- Documenting cloud deployment steps using GitHub.
